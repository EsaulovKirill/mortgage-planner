# Ипотечный планировщик

Личный адаптивный калькулятор аннуитетной ипотеки с несколькими сценариями досрочного погашения. Все данные сохраняются только в браузере пользователя.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверки проекта:

```bash
npm test
npm run build
```

## Публикация на GitHub Pages

1. Создайте новый репозиторий GitHub и загрузите в него содержимое этой папки.
2. В настройках репозитория откройте **Settings → Pages**.
3. В поле **Source** выберите **GitHub Actions**.
4. Отправьте изменения в ветку `main` — workflow `.github/workflows/deploy.yml` сам проверит, соберёт и опубликует приложение.

Приложение использует относительные пути, поэтому работает и на домене пользователя, и в подпапке репозитория GitHub Pages.

## Важно

Расчёт является прогнозным. Он использует календарную схему Actual/Actual и правила из технического задания, но фактический банковский график определяется кредитным договором и внутренними правилами банка.
